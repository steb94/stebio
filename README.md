## STEB.io Marketplace Backend

This directory contains a simple Express backend that demonstrates core functionality for the STEB.io digital marketplace.  It provides endpoints for user registration, login and CRUD operations for products.  The current implementation stores data in memory and should be replaced with a database (e.g. PostgreSQL) in production.

### Prerequisites

- Node.js (version 14 or later)
- npm or yarn
